Track A Field Test Board

Presentation-aligned HADO Smart Court IoT test plan for single-camera tracking, bird-eye tactical guidance, and pose-based action demo.

Scope guard: Track A only. Do not mix Roboflow relabeling, AR effect occlusion, player-only retraining, or Track B research outputs into tomorrow's test.

1. Presentation Architecture

Fixed Camera One court-facing camera captures live HADO movement. single camera
→
Raspberry Pi 4 YOLOv8n-pose extracts player boxes and 17 keypoints. NCNN is the preferred field model. edge inference
→
Tracking + Homography IoU tracker keeps player IDs. Foot points are transformed from pixels to court meters. bird-eye coordinates
→
Tactical + Action Layer Rule engine creates explainable guidance. Pose keypoints drive 7 HADO action labels. demo output

2. Three Demo Levels

Level 1 Tracking

  • YOLOv8n-pose player detection
  • bbox bottom-center foot point
  • IoU player ID tracking
  • court meter coordinates

Level 2 Tactical Engine

  • rule-based advice
  • MID/HIGH urgency visual output
  • optional offline voice guide
  • presentation demo recording

Level 3 Action Demo

  • skeleton overlay
  • charge, shoot, shield
  • dodge left/right, crouch, ready
  • prototype confidence panel
